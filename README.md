# ZEEHO
> ⚠️本项目仅用于学习研究，禁止商用，使用产生一切风险自行承担

极核ZEEHO电动车Loon脚本，包含自动签到、社区积分任务、盲盒抽奖、车辆状态看板、远程车辆控制。
HTML可视化BoxJS面板，支持多账号管理，自动抓取Token，无需手动复制大量请求头。

## ✨主要功能
### 📅签到&积分任务
- 每日自动签到，统计连续签到天数
- 社区互动任务：发帖、点赞、分享，获取积分
- 满30天自动开启签到盲盒
- 运行日志持久化，面板展示**真实今日总积分（签到+互动+盲盒）**
- 多账号同时支持，签到状态一目了然

### 🚗车辆状态监控（读取）
- SOC电量、续航、电压、充电电流、充电状态
- 前后胎压、胎温
- 总里程、今日骑行里程、骑行时长
- 座垫锁状态、整车锁状态、蜂窝信号
- 服务到期时间展示

### 🎛️远程车辆控制（4G下发指令）
> ⚠️会真实操作车辆，请在车辆附近谨慎操作，误触风险自负
1. 🔔寻车：车辆闪灯
2. 📣鸣笛寻车：鸣笛+闪灯
3. 💺弹开坐垫
4. 🔓云端开锁
5. 🔒云端关锁

每个操作带二次确认弹窗，返回执行结果提示。
