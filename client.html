上传账号配置

使用流程

1. 填写账号名称、用户ID、Authorization
2. 点击「本地验证」：先离线校验格式，再联网验证 Token（直连失败自动走代理，不需要 Loon）
3. 验证通过后「Bark 上传」按钮才会解锁
4. 点击「Bark 上传」推送到手机
5. 手机端 Loon 拦截 Bark 请求，保存配置到面板并运行签到
⚠️ 验证在客户端本地完成，不依赖 Loon；只有最后一步保存配置需要手机开着 Loon

查询签到 & 车辆信息

🔔 绑定 Bark API（接收查询结果）
填入你自己的 Bark Key，查询结果将推送到这个 Key 对应的设备。查询前自动验证可用性。
💡 仅验证 Token 用极核 API；查询通过 Bark 发送请求，服务端处理后结果通过 Bark 通知推送回手机。

📱 苹果 iOS 抓包教程（Stream）

推荐 Stream，App Store 免费下载
1. App Store 下载 Stream
2. 打开 Stream →「开始抓包」→ 安装 CA 证书
3. 设置 → 通用 → 关于本机 → 证书信任设置 → 开启 Stream
4. 回到 Stream 点击「开始抓包」
5. 打开极核 App → 进入「我的」页面
6. 回到 Stream → 停止抓包 → 查看抓包历史
7. 搜索 zeehoev.com，点任意请求
8. 请求头找 Authorization，复制 Bearer 后面的 UUID
9. 请求头找 user_id，即为用户ID

🤖 安卓 Android 抓包教程（HttpCanary 小黄鸟）

安卓7以上需 Root 或虚拟机（VirtualXposed）
1. 下载安装 HttpCanary（小黄鸟）
2. 打开小黄鸟 → 安装 CA 证书
3. 目标应用选择「极核 ZEEHO」
4. 点击开始抓包（绿色播放按钮）
5. 打开极核 App → 进入「我的」
6. 回到小黄鸟 → 停止抓包
7. 找到 zeehoev.com 域名请求
8. 请求头复制 Authorization 中 Bearer 后的 UUID
9. 同位置找到 user_id 即为用户ID

🔑 字段格式说明

完整 Authorization：Bearer f4f49d9c-e558-4887-a139-dffa9068c4f9
需要的 Token：f4f49d9c-e558-4887-a139-dffa9068c4f9（去掉 Bearer 和空格）
用户ID：纯数字，如 20251009000440652

📋 Bark autoCopy 自动复制教程

查询结果通过 Bark 推送时携带 autoCopy=1 参数， 推送内容会自动复制到手机剪切板，然后在网页点「解析剪切板」即可显示查询结果。

使用步骤：
1. 在查询页填写 Token 和绑定 Bark Key，点「验证」确认绑定Key可用
2. 点「查询信息」，客户端通过自带 Bark API 发送查询请求
3. 服务端（Loon）拦截请求，查询极核 API，向绑定 Bark Key 推送结果（带 autoCopy=1）
4. 手机收到 Bark 通知，下拉通知栏触发自动复制（iOS14.5+长按或下拉即可）
5. 回到网页，点「📋 解析剪切板」，查询结果显示在网页上

注意事项：
· Bark App 需在后台运行，通知权限已开启
· iOS14.5 之后需要长按或下拉推送才能触发自动复制
· 网页读取剪切板需要浏览器授权（首次会弹窗询问）
· 如果解析失败，检查剪切板内容是否为JSON格式
